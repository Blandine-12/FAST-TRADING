# 🛒 Fast Trading Marketplace System

A simple **web-based marketplace system** built using **HTML, Bootstrap, and JavaScript (localStorage)**.  
It allows users to submit buying/selling requests and lets an admin approve or reject them.

---

## 🚀 Features

### 👤 User Features
- Create account
- Login system
- Submit **Buy requests**
- Submit **Sell requests**
- Check request status (Pending / Approved / Rejected)
- Contact support page

### 🧑‍💼 Admin Features
- Admin login
- View all requests (Buy + Sell)
- Approve requests
- Reject requests
- Manage marketplace workflow
